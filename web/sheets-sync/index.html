AGAPE Sheets Sync

Внутренний инструмент организаторов AGAPE CAMP и TRES DIAS для синхронизации регистрационных анкет с двумя отдельными Google-таблицами.

Новые анкеты поступают с сайтов в базу данных. Скрипт переносит их в таблицы и передаёт изменения разрешённых полей из таблиц обратно в базу. Изменения из админки также появляются в таблицах.

Google-доступ нужен владельцу скрипта для чтения и обновления таблиц, установки обработчиков изменений и регулярного запуска. Участникам мероприятий вход через Google не требуется.

Доступ к самим таблицам определяется их настройками общего доступа. Эта страница не предоставляет доступ к анкетам.
