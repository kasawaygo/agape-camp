# TRES DIAS 2027 в существующем AGAPE CAMP

Теперь обе анкеты работают в одном Go-сервисе и одной админ-сессии. Данные лагеря остаются в `public.registrations`; данные TRES DIAS записываются отдельно в `public.tres_dias_registrations`. Оба сервиса одновременно запускать не нужно.

## Перед публикацией изменений

1. В репозитории проверь изменения и отправь их в `main`. Render пересоберёт уже подключённый сервис `agape-camp`.
2. Перед тем как отправлять новый код, в Supabase открой SQL Editor и выполни весь файл `tres_dias_schema.sql`. Это создаст отдельную таблицу и ограничение на размеры S–5XL. SQL не удаляет и не меняет таблицу лагеря.
3. После успешного запуска проверь `/healthz`, затем открой `/tres-dias/` и отправь тестовую анкету.
4. Войди в старую админку по `/admin`; ссылка **TRES DIAS 2027** появится в левом меню. Там можно искать, фильтровать по типу анкеты, раскрывать ответы, удалять тестовые записи и скачивать Excel.

## Как пользоваться

- Общая анкета лагеря остаётся на главной странице.
- Публичная страница выбора анкеты TRES DIAS: `/tres-dias/`. Прямые ссылки: `/tres-dias/participant` и `/tres-dias/servant`.
- Админка TRES DIAS использует ту же авторизацию, что и админка лагеря: `/admin/tres-dias`.
- Excel содержит общий лист и отдельные листы для участников и служителей.

## Запуск локально

Из корневой папки проекта выполни `go run .`. Нужны уже настроенные переменные окружения и выполненный `tres_dias_schema.sql`. Не добавляй `.env` в Git и не присылай пароли в чат.

## Хранение до мероприятий

Render Free останавливается после 15 минут без входящих запросов, затем автоматически запускается при следующем открытии (обычно около минуты). Бесплатный веб-сервис не имеет срока удаления через 30 дней. Supabase Free может приостановить неактивную базу после примерно семи дней низкой активности. Для непрерывной готовности сайта и гарантированного доступа к БД используй платный сервис Render и платный проект Supabase.
